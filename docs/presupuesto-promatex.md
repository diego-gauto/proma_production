# Presupuesto - Sistema de Gestion de Produccion Textil

**Cliente:** Indumentaria Promatex  
**Proyecto:** Sistema web para seguimiento de ordenes de corte y produccion textil  
**Fecha:** Octubre 2026

## Descripcion del sistema

Se propone desarrollar un sistema web interno para que Indumentaria Promatex pueda ordenar, consultar y controlar el avance de sus ordenes de corte desde el inicio del proceso hasta la finalizacion de la prenda.

El sistema permitira ver rapidamente donde esta cada orden, que sector la tiene, si fue enviada a un taller externo, cuanto tiempo lleva en cada paso y que trabajos ya fueron realizados. El objetivo es reemplazar el seguimiento manual disperso por una herramienta centralizada, clara y facil de usar para produccion, administracion y los sectores de trabajo.

## Alcance incluido

- Carga y consulta de ordenes de corte con cliente, articulo, tela, curva de talles, cantidades y observaciones.
- Listado general de ordenes para ver el estado de cada trabajo en curso.
- Vista por sectores, para que cada area vea las ordenes que debe trabajar.
- Registro de avance por etapa: Corte, Bordado, Estampado, Avios, Confeccion, Atraque, Ojal y Boton, Plancha y Terminacion.
- Posibilidad de dividir una orden en partes cuando una parte avanza por un camino y otra queda pendiente o va a otro taller.
- Registro de trabajos enviados a talleres externos cuando corresponda.
- Carga de inicio y fin de cada trabajo, con notas internas y responsable.
- Estado de orden en Arreglo, con detalle del problema y posterior resolucion.
- Control operativo de avios por orden o parte, indicando si estan completos, parciales o faltantes.
- Carga de datos basicos necesarios para operar el sistema: clientes, talleres externos, articulos, telas, avios, talles, usuarios y permisos.
- Acceso con usuario y clave, con permisos segun el rol de cada persona.

## No incluye

- Sistema de stock de telas y avios.
- Avisos de bajo stock.
- Descuento automatico de telas o avios contra ordenes de corte.
- Integracion con archivos de bordados o estampados.
- Notificaciones internas o avisos automaticos dentro de la aplicacion.
- Facturacion, precios, costos o contabilidad.
- Gestion de pedidos de cliente que agrupen varias ordenes de corte.
- Despacho al cliente final.
- Lectura o generacion de codigos QR.
- Integraciones externas con ERP, ecommerce, sistemas contables, email o Telegram.

## Plazo estimado

El plazo estimado de desarrollo es de **3 meses**, contemplando armado del sistema, pantallas principales, carga de datos, flujo de ordenes de corte, seguimiento por sectores, pruebas y ajustes finales.
